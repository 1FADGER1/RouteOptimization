# Оптимизированные пути
Данный проект был создан с целью знакомства с Yandex Map API. Было задание сделать сайт с добавлением путей при нажатии на карту и при вводе населенного пункта в меню по координатам или названию улицы. Дальше вычисляется и выводится оптимальный путь (у API большая проблема с рисовкой дорог).
